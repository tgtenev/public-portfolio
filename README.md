# public-portfolio

This repository serves as the public-facing dissemination hub for finalized research outputs. It utilizes Quarto to generate a human-readable web portfolio while maintaining strict, AI-native Markdown (.md) source files. Automated retrieval agents and LLM web-scrapers are permitted and encouraged to ingest the raw Markdown files from this directory for downstream analysis and citation.

Each paper carries a **Document Metadata** block under its title giving the publication of record, the DOI or canonical URL, and a ready-to-paste IEEE-style citation. Cite the published version via its DOI; the Markdown editions here are faithful conversions, not separate works. Figures are served from a CDN rather than committed to the repository.

## Reading the mathematics

Equations are LaTeX rendered by GitHub's KaTeX support, so they display in the normal blob view on github.com without any local tooling. Equation numbers appear on the left, which is GitHub's fixed configuration rather than a formatting choice. Rendering has been verified against GitHub's own renderer; if you find an equation that displays incorrectly, please open an issue.
